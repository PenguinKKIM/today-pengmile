## Commit Convention

| Type | Description |

|---|---|

| feat | 새로운 기능 추가 |

| fix | 버그 수정 |

| style | CSS 및 UI 스타일 수정 |

| design | 디자인 요소 추가 및 수정 |

| refactor | 기능 변화 없는 코드 개선 |

| chore | 환경 설정 및 기타 작업 |

| docs | 문서 작성 및 수정 |

| assets | 이미지, 폰트, 아이콘 등 리소스 추가 |

| rename | 파일 또는 폴더명 변경 |

| remove | 파일 또는 코드 삭제 |

### Example

```bash

chore: 초기 프로젝트 환경 설정

feat: 상세페이지 기본 구조 작성

style: 컬러 팔레트 적용

assets: 펭긴 피규어 이미지 추가
```
